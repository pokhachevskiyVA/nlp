# Как запускать прогон — инструкция

Всё ниже проверено на реальных данных. Пути даны от корня папки Батя.

## Что где лежит

```
Код_прогона/
  gas.py              обработка одного человека: газ + RR -> точки и маркеры
  rr_result.py        программа Даниила, разбивка RR на периоды
  run125.py           пакетный прогон газовых файлов (пример пакетника)
  full_new.py         полный набор признаков по одному человеку (газ + RR)
  gasonly.py          только газовые признаки, когда RR того же теста нет
  rronly.py           только RR-признаки, когда нет газа
  merge125.py         вливание новых признаков в полную таблицу
  cpet.py             корреляционный прогон: плеяды и отчёты
  analyze.py          отбор признаков и функция draw() — та самая отрисовка плеяд
  report2.py          краткий и полный отчёт по группе
  sport_report.py     свод по виду спорта
  domains.py          классификатор признаков по системам
  rebuild_groups.py   пересборка групповых таблиц
  mk_dlit.py          сборка длительность_и_нагрузка.xlsx
  prog/               модули из ноутбука: pleiad_engine, spearman_core, ml_engine и др.
  разметка/           detail.jsonl, detail2.jsonl, feat125.jsonl, run125_list.json
```

Зависимости: `pandas`, `numpy`, `scipy`, `matplotlib`, `openpyxl`, `plotly`.

---

## 1. Один человек

`gas.make()` — единственная функция, которая нужна. На вход два пути: RR и газ.

```python
import sys, io, contextlib
sys.path.insert(0, 'Код_прогона')
import gas

r = gas.make(
    rr_path='Самарский RR/Фамилия Имя Отчество_ДОО_Рамп (+30Вт)_Фамилия_1_11_2024.rr',
    gas_path='Самарский СРЕТ/20241101 Имя Фамилия (CPET вдох за вдохом)_20250702114524.xlsx',
    report_only=True,        # не строить HTML — быстро
    prestart_s=30, start_s=30,
    hr_thresholds=(100, 125),  # пороги восстановления, теперь параметр
    doo_s=180.0)               # длительность ДОО-фазы для точки «коноо»
```

Возвращается словарь:

| ключ | что внутри |
|---|---|
| `load_start` | начало нагрузки, с (шкала газоанализатора) |
| `rec_start` | начало восстановления, с (та же шкала) |
| `offset_s` | сдвиг шкалы RR относительно газа |
| `hr_corr` | качество синхронизации, 0–1; ниже 0,85 — проверить RR |
| `hr_peak` | пиковая ЧСС |
| `detail` | словарь точек: `т1`…`т4`, `коноо`, `восст_1мин`, `восст_2мин`, `восст_замедление`, `восст_max_RER`, `восст_ЧСС<100`, `восст_ЧСС<125` |

В каждой точке: `t`, `pct` (% от МПК), `VO2`, `VCO2`, `RER`, `VE`, `VE/VO2`,
`VE/VCO2`, `RR`, `O2pulse`, где есть — `ЧСС` и `HRR`.

`report_only=False` вместо словаря строит интерактивный HTML с графиками —
полезно, когда точку надо посмотреть глазами.

Без RR того же визита используйте `gasonly.py`: он строит синтетический RR-ряд
из столбца ЧСС самого газового файла, поэтому синхронизация становится
тождественной, и все газовые точки считаются на шкале газа.

## 2. Пакетно

Образец — `run125.py`. Схема простая: список задач в JSON, скрипт берёт срез.

```bash
# список: [[ФИО, путь_RR, путь_газ, вид_спорта], ...]
python3 run125.py 0 22     # первые 22
python3 run125.py 22 22    # следующие 22
```

Срезами — потому что один человек считается 3–8 с, и на 85 записях
процесс упирается в таймаут. Результат дописывается в `feat125.jsonl`,
по строке JSON на человека. Перед новым прогоном файл удалить.

Готовый выверенный список путей — `разметка/run125_list.json`, 85 записей.
Ещё удобнее брать пути из `Словарь_ФИО_и_путей.xlsx`: там `ФИО_в_таблице_признаков`
и оба пути лежат в одной строке.

## 3. Сборка полной таблицы

`merge125.py` — рабочий пример: читает `feat125.jsonl`, приклеивает признаки
к таблице по ключу ФИО, пишет новую книгу с суффиксом даты.

Принцип: **никогда не перезаписывать существующую таблицу**, всегда новый файл
`Полная_таблица_признаков_ГГГГ-ММ-ДД.xlsx`. Листы: `Лыжники`, `Баскетболисты`.
Ключ — первый столбец, ФИО ровно как в таблице Данила.

## 4. Корреляционный прогон и плеяды

```bash
python3 cpet.py --список-целей
python3 cpet.py --цель мощность --признаки газ --спорт оба --выход ИмяПапки
```

Параметры: `--цель` (мощность / экономичность / пульсовая_цена),
`--признаки` (газ / rr / все), `--спорт` (оба / лыжники / баскет),
`--без-кластеров`.

Новая цель добавляется функцией в словарь `TARGETS` внутри `cpet.py`.
Функция принимает датафрейм и возвращает `(Series, 'Название цели')`.
Отдельный скрипт писать не нужно.

На выходе в каждой подгруппе: `Плеяда_1_ведущие.png`, `Плеяда_2_по_доменам.png`,
`Отчёт_краткий.html`, `Отчёт_полный.html`, `Значимые_признаки.xlsx`.

**Плеяды рисует только `draw()` из `analyze.py`.** Это точный порт кода из
программы Даниила: цель в центре жёлтым, признаки по кругу голубым, подписи
снаружи, толщина ребра `0.7 + 6.5*|r|`, красный «+» и синий «−», рисуются все
значимые связи, включая связи между признаками. Своих реализаций не писать.

Линия между признаками не рисуется в трёх случаях: `p ≥ 0.05`; меньше четырёх
общих наблюдений; один из признаков — константа. Отдельного порога по `|r|` нет,
эффективный порог задаётся объёмом выборки: 0,288 при n=47 и 0,433 при n=21.

## 5. Порядок при добавлении новых людей

1. Положить файлы, найти пары газ+RR **по дате теста изнутри книги**, а не по имени файла.
2. Дописать строки в `Словарь_ФИО_и_путей.xlsx`.
3. Прогнать `run125.py` (или `full_new.py` для полного набора признаков).
4. Влить через `merge125.py` в новую книгу с сегодняшней датой.
5. Пересобрать группы через `rebuild_groups.py`.
6. Прогнать `cpet.py` по нужным целям.

## Грабли, на которые я наступал

- **Дата в имени файла не равна дате теста.** У выгрузок 2026 года префикс в
  имени — дата экспорта. Истина в поле «Дата теста» внутри книги. На старых
  файлах они совпадали в 25 случаях из 25, на новых расходятся на годы.
- **ФИО.** Нормализовать NFC (иначе «ё» не совпадёт), заменять латиницу на
  кириллицу, проверять порядок слов: «Азиз Саидов» — фамилия вторая.
  Два Фролова тестировались в один день, различать по имени.
- **Однофамильцы и повторные визиты.** Ключ по одной фамилии неуникален.
  Один человек тестировался дважды; сопоставление по фамилии дало обеим строкам
  данные одного визита.
- **Утечки цели.** Для целей, связанных с мощностью, исключать `мин_нагрузки`,
  `таргет_*`, `Пик нагрузки`, `Wmax`, `PWC`, абсолютные времена `газ_*_t`,
  периоды 4Н–9Н, `Ннак_N4/N5`. Зашито в `pick_features` внутри `cpet.py`.
- **Доля точки на нагрузке** считается от `load_start`, не от 60 с:
  `(t − load_start)/(rec_start − load_start)`.
- **Файлы на Яндекс.Диске нельзя удалить**, только перезаписать.
